# Hermes Logistics — DESIGN.md

## Overview

Hermes is a logistics platform that has to feel **precise, nocturnal and in
motion**. The identity is dark-first: a near-black navy void (`background`,
`#01051D`) that reads like a night map, lit by a small number of saturated
signal colors — cyan, amber, sunset orange — that behave like beacons, not
decoration.

Three principles drive every decision:

1. **Darkness is the substrate, light is the signal.** Dark mode is the primary
   mode. Light mode exists (page 1.1 / 1.5) but is the derived variant, with its
   own deeper primaries so contrast survives the inversion.
2. **One typeface, many voices.** Poppins carries the entire system. Hierarchy
   is expressed through size and weight on a Material-style five-tier scale,
   never through a second family.
3. **Accents are rationed.** A screen shows one dominant accent. Cyan, amber and
   orange are peers, not a gradient set — mixing all three in one component is
   noise, not brand.

Two surface families coexist and must not be blended inside one screen:

- **Cool / Navy** (`background`, `surface`, `foreground`) — marketing landing,
  onboarding, auth. This is the brand default.
- **Warm / Bronze** (`surface-warm` `#0E0C0A`, `surface-warm-raised` `#201A12`,
  `foreground-warm` `#F4EFE7`) — the operations dashboard, where dense data sits
  for long sessions and pure navy would vibrate against the map tiles.

Canonical source: the `Design system` frame (node `I5xP6`) in `pencil.pen`,
pages **1.0** palette → **1.1** light palette → **1.2/1.3** usage proportion →
**1.4/1.5** shades → **1.6** contrast → **1.7** logotype → **2.0** typography.
Read it with the pencil MCP tools; never with `Read`/`Grep`.

## Colors

### Roles

| Role | Token | Value | What it is for |
| --- | --- | --- | --- |
| Canvas | `background` | `#01051D` | The page itself. Never used on text. |
| Surface | `surface` | `#001751` | Cards, panels, elevated blocks on the canvas. |
| Raised surface | `surface-raised` | `#152E6D` | Hover, selected rows, nested panels, secondary buttons. |
| Primary accent | `blue-sky` | `#61F0FF` | The single most important action or datum on a screen. |
| Warning / value accent | `light-yellow` | `#FFC152` | Attention states, pricing highlights, in-transit. |
| Alert accent | `sunset-orange` | `#FF734D` | Destructive actions, delays, exceptions. |
| Supporting accent | `turquoise` | `#4EC1D2` | Charts and secondary data series only. |
| Body text | `foreground` | `#EBF2FF` | All primary copy on dark surfaces. |
| Secondary text | `foreground-muted` | `#94A4C2` | Labels, captions, placeholder, disabled. |
| Hairline | `border-hairline` | `#D8D0C214` | 1px separators; borders are whispers, never lines. |

Light mode swaps the primaries for their deeper LM variants —
`deep-blue-lm` `#031E72`, `blue-sky-lm` `#00DBFF`, `sunset-orange-lm` `#FF501A`,
`bright-orange-lm` `#F4AD21` — over a `#FFFFFF` / `soft-blue-lm` `#EBF2FF`
canvas with `neutral-900` `#141923` text. Do not reuse the dark-mode hexes on a
light canvas: `#61F0FF` on white fails every contrast target.

### Proportion

Pages 1.2 and 1.3 fix the mix. Read it as roughly **60 / 30 / 10**:

- **~60%** dominant base — `deep-blue` in dark mode, `soft-blue-lm` in light.
- **~30%** foreground and neutrals — text, icons, hairlines.
- **~10%** accents, split evenly between cyan, amber and orange. The three
  accents get *equal* share; none is allowed to become the de-facto background.

### Ramps

Each brand color has a six-step ramp (pages 1.4 / 1.5) running from a near-black
tint at `-600` to a pale tint at `-100`. Use `-500`/`-200` as the "true" brand
value, `-600`/`-500` for tinted backgrounds behind an accent (badge fills, chart
bands), and `-100`/`-200` for text or icons sitting *on* those tinted
backgrounds. Never invent an intermediate step — the ramps exist so that
generated UI lands on the same values twice.

## Typography

Poppins, single family, loaded at 300/400/600/700/800 from `public/fonts/`.
The scale is Material-style with five tiers (page 2.0):

| Tier | Token | Size / Line height | Weight | Use |
| --- | --- | --- | --- | --- |
| Display | `display-lg` / `md` / `sm` | 57/68 · 45/52 · 36/44 | 700 | Hero statements only — one per screen. |
| Headline | `headline-lg` / `md` / `sm` | 32/40 · 28/36 · 24/32 | 500 | Section openers on marketing and onboarding. |
| Title | `title-lg` / `md` / `sm` | 22/28 · 16/24 · 14/20 | 700 | Card titles, modal titles, table group headers. |
| Body | `body-lg` / `md` / `sm` | 16/24 · 14/20 · 12/16 | 400 | Paragraphs, table cells, descriptions. |
| Label | `label-lg` / `md` / `sm` | 14/20 · 12/16 · 11/16 | 500 | Buttons, form labels, badges, nav items. |

- **Weight carries meaning.** Display and Title are Bold (700); Headline and
  Label are Medium (500); Body is Regular (400). Do not bold body copy to create
  emphasis — promote it to `title-sm` or change its color instead.
- `body-md` (14px) is the workhorse for product UI; `body-lg` (16px) for
  marketing prose. Never go below `label-sm` (11px).
- `eyebrow` is `label-md` in Bold with `0.08em` tracking, uppercase — used for
  section numbering and category kickers.
- Measure: cap paragraphs at ~72 characters. On the landing page that means a
  fixed-width text box, not a full-bleed one.

## Layout

- **Breakpoints / artboards:** 390 (mobile), 768 (tablet portrait), 844 (tablet
  landscape), 1024 (small desktop), 1440 (desktop). Every landing section exists
  at all five widths in `pencil.pen`; a new section is not done until it does.
- **Spacing scale:** 4px base — 2, 4, 6, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80.
  Values off this scale are a bug. 8 and 16 do most of the work; 32 separates
  major regions; 64/80 separate landing sections.
- **App shell:** sidebar `256px` (collapsed rail `72px`) + main `1184px` at a
  1440 viewport. Topbar is `64px` tall with `0 32px` padding. The content region
  uses `32px` side/bottom padding and a `16px` vertical gap between blocks.
- **Sidebar internals:** `16px` frame padding, `2px` gap between nav items,
  `32px` item height, `8px` item radius.
- **Marketing rhythm:** sections are full-bleed at the artboard width with an
  internal max content column; vertical padding of 64–80px top and bottom.
- Flexbox only — single-axis. Grid-like arrangements are built as explicit row
  frames, and children use `fill_container` rather than repeated pixel widths.

## Elevation & Depth

Depth is **tonal and atmospheric**, not shadow-driven.

1. **Tonal layers.** Lift is a step up the Deep Blue ramp:
   `background #01051D` → `surface #001751` → `surface-raised #152E6D`. On the
   warm dashboard: `#0E0C0A` → `#15120D` → `#201A12`.
2. **Hairline borders.** A 1px `#D8D0C214` stroke defines an edge where two
   tonal layers are too close to read. Borders are always 1px, always
   inner-aligned, never a saturated color.
3. **Ambient lights.** Dashboard and hero canvases carry an absolutely
   positioned `Ambient Lights` group: 680–820px radial-gradient ellipses in
   cyan (`#61F0FF24`) and warm orange (`#FF9D5C3D`) fading to fully transparent,
   with a 64–72px blur. They sit behind content, never over it, and are the only
   sanctioned "glow".
4. **Shadows are minimal.** At most a `0 1px 1.75px #0000000d` outer shadow on
   cards. No colored shadows, no multi-layer drop shadows, no neon outer glow on
   text or buttons.

Order of preference when something must come forward: tone → hairline → ambient
light → shadow. If the first three do the job, skip the shadow.

## Shapes

Radii are small and consistent — the brand reads engineered, not soft.

| Token | Value | Applied to |
| --- | --- | --- |
| `xs` / `sm` | 3–4px | Chips, tags, tiny indicators, chart bars. |
| `md` | 6px | Buttons, inputs, selects, menu items, tooltips. |
| `lg` | 8px | Cards, table containers, sidebar items, dropdowns. |
| `xl` / `2xl` | 12–16px | Modals, sheets, large feature panels, hero media. |
| `full` | 9999px | Pills, badges, avatars, toggle tracks, status dots. |

One radius per element — never mix corner values on a single frame. Container
and its children should differ by one step at most (an 8px card holding 6px
buttons). Illustrations and the logo mark are the only places freeform curves
appear; everything structural is a rounded rectangle or an ellipse.

## Components

The `pencil.pen` library is shadcn-derived. Reusable components live at the top
of the canvas under `K:*` ids (`K:VSnC2` Button/Default, `K:pcGlv` Card,
`K:1415a` Input Group/Default, `K:bG7YL` Table, `K:PV1ln` Sidebar, …) and expose
shadcn semantic variables (`K:--primary`, `K:--card`, `K:--border`) themed by
the `K:Mode = Dark` axis. **Instance these components; do not redraw them.**

Two overrides always apply when instancing them into a Hermes screen: the
primitives ship with shadcn's **Inter** default and neutral `K:--*` colors —
override the text to **Poppins** and re-point fills to the Hermes tokens above.
The geometry (heights, radii, padding) is already correct; leave it alone.

- **Buttons.** Height 36 (default) / 40 (large), 6px radius, `8px 16px` padding,
  `6px` gap between icon and label, label at `label-lg`. Variants: Default
  (accent fill, dark label), Secondary (raised surface), Outline (hairline
  border, transparent fill), Ghost (muted label, no chrome), Destructive
  (`sunset-orange` fill, dark label). One Default button per view.
- **Icon buttons.** Square, 36 or 40px, same radius and variants.
- **Cards.** `surface` fill, 1px hairline, 8px radius, header/content/actions
  stacked with `24px` padding and `8px` internal gap.
- **Inputs.** 40px tall, 6px radius, hairline border, `12px` horizontal padding,
  value at `body-md`, placeholder at `foreground-muted`. The label sits above at
  `label-md` with an `8px` gap; helper and error text below at `body-sm`, error
  in `sunset-orange`. Focus is a `ring` outline, not a glow.
- **Badges.** 20px tall, pill radius, `label-sm`. Status mapping is fixed:
  delivered/ok → `blue-sky`, in transit/pending → `light-yellow`, delayed or
  failed → `sunset-orange`, neutral/draft → `surface-raised` with muted text.
- **Tables.** 44px rows, 40px headers, hairline row separators, no zebra
  striping, no vertical rules. Headers are `label-md` in `foreground-muted`;
  numeric columns are right-aligned.
- **Sidebar.** 256px, warm gradient fill, 32px items at 8px radius; the active
  item is a filled `surface-warm-raised` block with full-opacity text, inactive
  items are muted with no chrome.
- **Modals & sheets.** 12–16px radius, `24px` padding, `16px` gap, over a scrim.
  Title at `title-lg`, body at `body-md`, actions right-aligned with the Default
  button last.
- **Tooltips.** `surface-overlay` `#0A1740` fill with a `border-cool` `#B7CDF547`
  1px border, 6px radius, `6px 12px` padding, 13px text, wrapped at ~220px.
- **Logotype.** Use the prepared assets in `pen-assets/` — `logo-full-navy-*`,
  `logo-full-dark-*`, `logo-full-light-*` (full lockup), `logo-short-*` (short
  lockup), `logo-mark-*` / `logo-hdot-*` (mark only). Pick the variant whose
  background matches the surface; never recolor, restretch, rotate or rebuild
  the logo from shapes. Minimum clear space on all sides equals the height of
  the "H". Minimum full-lockup width 120px; below that use the short lockup or
  the mark.

## Do's and Don'ts

**Do**

- Start from dark mode; derive light mode from the LM tokens on page 1.1/1.5.
- Pick one accent per screen and let the other two appear only as status.
- Take every accent/text pairing from the contrast table in the Colors section.
- Snap every size, gap and padding to the 4px spacing scale.
- Instance the `K:*` components and override their slots, rather than drawing
  new buttons, inputs or cards.
- Express hierarchy with tonal layers and hairlines before reaching for shadow.
- Keep Poppins as the only family; change size and weight, not typeface.
- Ship a landing section at all five artboard widths before calling it done.
- Generate logos, illustrations and decorative artwork as SVG/image assets —
  never hand-assemble them from paths.

**Don't**

- Don't put white text on `blue-sky`, `light-yellow` or `sunset-orange` — bright
  accents always take `#01051D`.
- Don't mix the cool navy surfaces with the warm bronze dashboard surfaces in a
  single screen.
- Don't use cyan, amber and orange together as a gradient or a tri-color fill.
- Don't add neon glows, colored shadows, or blurred backdrops outside the
  sanctioned `Ambient Lights` group.
- Don't invent hexes between the six ramp steps, and don't apply opacity to a
  brand color to fake a tint — use the ramp.
- Don't set body text below 12px, or use bold weight on body copy for emphasis.
- Don't wrap every element in its own card; a container needs a structural
  reason to exist.
- Don't use rounded corners above 16px on structural UI, and never mix radii on
  one frame.
- Don't edit `pencil.pen` with `Read`/`Grep`/`Write` — it is encrypted and only
  the pencil MCP tools may touch it.
